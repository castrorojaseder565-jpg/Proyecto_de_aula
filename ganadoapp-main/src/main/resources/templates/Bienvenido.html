Antes de entrar, lo esencial.

Respuestas cortas sobre cómo se usa BoviControl.

¿Es una aplicación web o una app de tienda?

Es una aplicación web responsive: se usa desde el navegador en computador, tablet o celular.

¿Qué roles existen?

Administrador y veterinario, cada uno con permisos distintos para inventario, vacunas y usuarios.

¿Qué información puedo gestionar?

Fichas de bovinos, vacunas, alertas sanitarias, planes de alimentación, predicción de leche y usuarios del equipo.

¿Cómo entra un veterinario?

El administrador envía una invitación por correo. El veterinario activa su cuenta con ese enlace.
